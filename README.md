## ◇ About

I like turning recurring problems into **small, focused products**.

<table>
<tr>
<td width="25%" align="center" valign="top">

### Local-first

Keep data and workflows under the user's control.

</td>

<td width="25%" align="center" valign="top">

### Useful first

Solve the real problem before adding complexity.

</td>

<td width="25%" align="center" valign="top">

### Extensible

Give users and developers room to make tools their own.

</td>

<td width="25%" align="center" valign="top">

### Long-term

Shipping is the start. Reliability and iteration come next.

</td>
</tr>
</table>

<details>
<summary><b>▸ How I like to build software</b></summary>

<br />

I prefer software that feels simple on the surface but leaves enough depth underneath.

That usually means:

* sensible defaults
* fewer unnecessary abstractions
* local ownership of data
* transparent behavior
* extensibility where it matters
* continuous iteration after release

Most of my work sits somewhere between **developer tools, AI agents, desktop software, self-hosting, and automation**.

</details>
